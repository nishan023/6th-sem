# BSc CSIT 6th Semester Labs Repository

Welcome to the repository containing code solutions for the lab assignments undertaken during the sixth semester of the Bachelor of Science in Computer Science and Information Technology (BSc CSIT) program at Tribhuvan University, Nepal.

## Description

This repository includes lab works, practical implementations, and supporting materials for the sixth-semester courses of the BSc CSIT curriculum. The labs focus on software development methodologies, e-governance concepts, network-centric applications, and e-commerce systems.

## How to Use

To access the lab materials for a specific subject:

1. Navigate to the respective subject folder using the links provided above.
2. Explore the folder to find source code, documentation, and lab resources.
3. Use the output links to view execution results, screenshots, or reports if available.
